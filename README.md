# ⚡ Calculadora de Consumo de Energia

# 📌 Sobre o projeto

A Calculadora de Consumo Elétrico é um programa desenvolvido para estimar o consumo mensal de energia elétrica de um aparelho doméstico.

O sistema utilizado para programação foi o Python e, utiliza informações simples, como a potência do aparelho e o tempo médio de utilização diária, para calcular uma estimativa de consumo em kWh/mês.

Além disso, o programa calcula uma estimativa do custo mensal da energia em reais.

# Tecnologias utilizadas
 Python   
 Git  
 GitHub  
 Markdown  

# 💻 Exemplo de utilização

Digite o nome do aparelho: Geladeira  
Digite a potência do aparelho em watts (W): 150  
Digite o tempo médio de uso diário (horas): 10  

Aparelho: Geladeira  
Consumo estimado: 45.00 kWh/mês  
Custo estimado em reais: R$ 33.75
